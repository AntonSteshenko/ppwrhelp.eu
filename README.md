# PPWR Desk

Applicazione Next.js con App Router e TypeScript.

## Visione del progetto

PPWR Desk sarà un sito multilingua, disponibile nelle 24 lingue ufficiali dell'UE, dedicato alla normativa UE sugli imballaggi e i rifiuti di imballaggio (PPWR). Dovrà contenere:

- un quiz per aiutare i visitatori a verificare la propria comprensione della normativa;
- una libreria di risorse e riferimenti normativi;
- una sezione news con aggiornamenti sul PPWR.

Il sito dovrà essere ottimizzato per la ricerca tradizionale (SEO) e per la scoperta e comprensione dei contenuti da parte dei sistemi di intelligenza artificiale. Questo è il brief iniziale del progetto: contenuti, pubblico, funzionalità dettagliate e strategia editoriale saranno definiti durante la progettazione.

## Avvio

```bash
npm install
npm run dev
```

Apri [http://localhost:3000](http://localhost:3000). La pagina iniziale si trova in `src/app/page.tsx`.

## Verifiche

```bash
npm run typecheck
npm run build
```
